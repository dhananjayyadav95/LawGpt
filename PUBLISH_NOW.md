# 🚀 Publish Nepal Law Assistant NOW (5 Minutes)

## 🎯 **Fastest Path to Live Deployment**

### **Step 1: Get Free API Key (2 minutes)**
1. Go to https://makersuite.google.com/app/apikey
2. Sign in with Google account
3. Click "Create API Key" 
4. Copy the key ✅

### **Step 2: Deploy Backend (2 minutes)**
1. Go to https://railway.app/
2. Click "Deploy from GitHub repo"
3. Connect your GitHub account
4. Select this repository
5. Choose "backend" folder as root directory
6. Add these environment variables:
   ```
   AI_PROVIDER=google
   AI_MODEL=gemini-pro
   GOOGLE_API_KEY=your_api_key_from_step1
   MONGO_URL=mongodb://localhost:27017/nepal_law
   CORS_ORIGINS=*
   ```
7. Click Deploy ✅

### **Step 3: Deploy Frontend (1 minute)**
1. Go to https://vercel.com/
2. Click "Import Project"
3. Select this repository
4. Set root directory to "frontend"
5. Add environment variable:
   ```
   REACT_APP_BACKEND_URL=https://your-railway-url.railway.app
   ```
6. Click Deploy ✅
